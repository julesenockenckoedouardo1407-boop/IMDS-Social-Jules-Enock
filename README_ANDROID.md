# Compilation Android

Le workflow `.github/workflows/build-apk.yml` construit un APK Debug automatiquement.

1. Envoyer tous les fichiers du projet dans GitHub.
2. Aller dans l'onglet **Actions**.
3. Ouvrir **Construire APK IMDS Social**.
4. Appuyer sur **Run workflow** si nécessaire.
5. Une fois terminé, ouvrir l'exécution réussie.
6. Télécharger l'artifact `IMDS-Social-Jules-Enock-v2.0-APK`.
7. Décompresser l'artifact et installer `app-debug.apk` sur Android.

Cette version est une première compilation de test. La signature Play Store et les fonctions en ligne seront traitées plus tard.
