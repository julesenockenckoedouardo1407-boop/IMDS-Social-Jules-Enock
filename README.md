# IMDS Social Jules Enock v2.0

Projet Android/web léger pour l'Institution Mixte Le Domaine du Savoir (IMDS).

## v2.0 — Cœur du système
- Accueil
- Connexion / inscription
- Profils
- Rôles : Direction, Professeur, Élève, Parent
- Déconnexion
- Sauvegarde locale
- Interface mobile responsive

## Suite prévue
Publications synchronisées → Classes → Messages → Notifications → modules scolaires.

## Test local
Ouvrir `www/index.html` dans un navigateur.

## Android
Le dossier `www/` est prévu comme base web pour être ensuite emballé dans une application Android avec une solution compatible (par exemple Capacitor). Le projet n'est pas présenté comme un APK déjà compilé.
